# G3-2 三层许可核实与法务意见

> 原则：**代码许可 ≠ 权重许可 ≠ 训练数据集许可**。平台代码 Apache-2.0 不等于权重可商用。
> 「模型权重授权」子项已通过选型解决（YuNet + SFace，见 `model-inventory.md`），
> 但许可快照、三层出处、法务意见与组件扫描仍需留档。

| 层 | 对象 | 已知结论 | 需留档的证据 | 状态 |
|---|---|---|---|---|
| 代码 | CompreFace 平台（1.2.0） | Apache-2.0 | LICENSE 全文快照 + 出处 URL + 抓取日期 + 文件 hash | 待留档 |
| 代码 | OpenCV / OpenCV Zoo（含插件适配层） | Apache-2.0 | 同上；注明 `opencv-contrib-python-headless==4.9.0.80` | 待留档 |
| 权重 | `face_detection_yunet_2023mar.onnx` | 随 OpenCV Zoo 仓库分发，Apache-2.0 | 仓库内 LICENSE / NOTICE 快照、权重文件 SHA256 | 待留档 |
| 权重 | `face_recognition_sface_2021dec.onnx` | 同上 | 同上 | 待留档 |
| 训练数据 | WIDER FACE（YuNet 检测训练集） | 常见「仅研究用途」条款，须逐项核实 | 数据集许可页快照 + 条款原文摘录 | **待法务核实** |
| 训练数据 | CASIA-WebFace / WebFace260M（SFace 识别训练集） | 同上 | 同上 | **待法务核实** |
| 发行包 | 自定义镜像内全部组件 | 需确认无其它受限权重/组件 | `pip list` / SBOM / `docker images` 输出 | 待组件扫描 |

## 留档要求

1. 每个证据文件命名 `<层>-<对象>-<日期>.txt`，同目录另存 `sources.md` 记录出处 URL、抓取时间、SHA256。
2. 组件扫描输出 `component-scan.txt`，列出镜像内 Python 包及版本，标出非 Apache/MIT/BSD 许可项。
3. 法务意见须书面明确：所选权重与训练数据集许可允许本平台的商业调解场景使用；
   若训练数据集存在研究用途限制，须按自定义构建路径换入其它已授权权重并**重跑 G1/G2**。
4. 法务意见与组件扫描结果回填 `compreface/README.md` §2 表第 2、3 项与 §7 V7 行。
